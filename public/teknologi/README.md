# Logo teknologi

Taruh berkas SVG resmi di folder ini, lalu isi `logo` di
`content/teknologi.ts`, misalnya:

```ts
{ kelompok: "Framework", nama: "Laravel", singkat: "LV", logo: "/teknologi/laravel.svg" }
```

Ambil berkasnya dari halaman brand/press masing-masing proyek — jangan
menggambar ulang logo orang lain. Tanpa berkas, ubin memakai monogram dan
tampilannya tetap rapi.
